# Yiping Yin — personal website

Published at <https://yiping-yin.github.io/> through GitHub Pages, from `main`.

The September 2026 checkpoint includes:

- Interactive S&P 500 semicircles, competition highlights and personal profile.
- Training overview and P.Book's multi-instrument manual paper-trading desk.
- A strategy editor with browser-local drafts; Python execution requires the
  local P.Book runtime and is disabled on GitHub Pages.
- AI Quant Lab's public overview. Original notes and research attachments remain
  private and are not present in this repository or public build.

## Routes

- `/` — personal homepage, Training and Lab overviews.
- `/training.html#/market` — historical prices, simulated order book, orders,
  positions and fills for S&P 500, AAPL, MSFT and NVDA.
- `/training.html#/studio` — Python strategy editor.
- `/lab.html` — returns to the public Lab overview.

Prices are retained Yahoo Finance historical observations from 10 September
2026, with 390 original one-minute bars per instrument. The displayed order book,
cash, orders and executions are simulated. There is no broker connection or
live order placement. Browser accounts are local to each origin and do not sync
to the local development application.

`release.json` identifies the portfolio snapshot and historical tape checksums.
The public artifact was generated by the private P.Book source repository at
commit `019e248` using `npm run build:public`. The exporter copies only verified
public assets and market data, without reading the Obsidian vault.

The proposed Lab Map and independent Profile page remain in development and are
not included in this checkpoint. Earlier published study assets remain available
at their original paths.

For a local static preview, run `python3 -m http.server 4173 --bind 127.0.0.1`
and open <http://127.0.0.1:4173/>. No backend is required for manual paper trading.
