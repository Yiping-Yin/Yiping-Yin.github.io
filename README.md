# Yiping Yin — personal website

Published at <https://yiping-yin.github.io/> through GitHub Pages, from `main`.

The September 2026 checkpoint includes:

- Interactive S&P 500 semicircles, competition highlights and the Training and
  Lab overviews on the home page.
- A standalone profile page and a standalone Lab page.
- P.Book's multi-instrument manual paper-trading desk, with a Rank panel that
  compares completed strategy runs under identical conditions.
- A strategy editor with browser-local drafts; Python execution requires the
  local P.Book runtime and is disabled on GitHub Pages, so on this site the
  Rank panel shows its layout with no runs.
- AI Quant Lab's public overview. Original notes and research attachments remain
  private and are not present in this repository or public build; the Lab's
  entries are deliberately unlinked.

## Routes

- `/` — personal homepage with the Training and Lab overviews.
- `/profile.html` — the profile: selected work, experience, awards, toolkit, contact.
- `/lab.html` — the public Lab overview: the five-domain Theory map and the
  six-stage Practice pipeline.
- `/training.html#/market` — the desk: a simulated market of 26 instruments
  (ASML, AAPL, NVDA, SAP and TSLA; two dual listings; the OB5X ETF; ASML and
  OB5X futures and options), a simulated order book, orders, positions and fills.
- `/training.html?market=historical#/market` — the same desk on retained
  historical prices for the S&P 500, AAPL, MSFT and NVDA.
- `/training.html#/studio` — Python strategy editor.
- `/cycle-study.html` — an earlier standalone study of the full-circle time and
  price composition.

Two kinds of price data are published. The home-page semicircles and the
historical desk use retained Yahoo Finance observations from 10 September 2026,
390 one-minute bars per instrument. The default desk uses a deterministic
synthetic scenario (session dated 14 September 2026, currency `SIM`), 390 bars
per instrument, generated for teaching; those prices are not market data. In
both modes the order book, cash, orders and executions are simulated. There is
no broker connection or live order placement. Browser accounts are local to
each origin and do not sync to the local development application.

`release.json` identifies the portfolio snapshot and the checksums of the 26
synthetic tapes. The public artifact was generated by the private P.Book source
repository (commit `019e248` plus fixes made on 16 September 2026) using
`npm run build:public`. The exporter copies only verified public assets and
market data, without reading the Obsidian vault.

Earlier published study assets remain available at their original paths.

For a local static preview, run `python3 -m http.server 4173 --bind 127.0.0.1`
and open <http://127.0.0.1:4173/>. No backend is required for manual paper trading.
